# Фотографии товаров

Сайт показывает фото товара из этой папки по имени файла, привязанному к товару
в `assets/products.js` (поле — последний элемент массива товара). Если файла нет,
на карточке автоматически показывается SVG-значок категории — сайт не ломается.

## Как заполнить папку

Нужно **68 файлов** (по одному на «фототип» — сочетание подгруппы, стандарта и
покрытия). Полный список имён — в `images/_needed_files.txt`.

Вариант 1 — скачать по поисковым запросам (готовый скрипт):

    cd tools
    pip install openpyxl duckduckgo-search requests
    python download_images.py        # сохранит картинки в ../images? см. путь OUT в скрипте

Вариант 2 — положить свои фото с нужными именами (напр. `bolt-din933-ocinkovannyi.jpg`).

## Важно про авторские права

Скрипт берёт изображения из поиска (DuckDuckGo/Яндекс/Google). Права на такие
изображения не проверены — для коммерческого сайта используйте собственные фото
или снимки с подтверждённой лицензией. Имена файлов при этом оставьте из списка.
