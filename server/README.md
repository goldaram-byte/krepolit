# КРЕПОЛИТ — CRM backend

Node/Express + SQLite. Управляет каталогом, воронкой продаж, заказами,
клиентами, сотрудниками (роли и права) и отчётами. Раздаёт публичную
витрину и админ-панель (`/admin`).

## Запуск

```bash
cd server
npm install
node import_catalog.js   # импорт каталога из ../assets/products.js в БД
node seed.js             # администратор + демо-данные
npm start                # http://localhost:3000  (админка: /admin)
```

Демо-доступы после `seed.js`:
- Администратор: `admin@krepolit.ru` / `admin123`
- Менеджер: `smirnov@krepolit.ru` / `manager123`

Переменные окружения: `PORT` (3000), `JWT_SECRET` (обязательно задать в проде),
`DB_PATH` (путь к файлу SQLite).

## Возможности
- **Авторизация** — JWT в httpOnly-cookie, пароли bcrypt.
- **Роли и права** — admin (полный доступ) и manager с гранулярными правами:
  клиенты/воронка/заказы (только свои / все), редактирование каталога,
  отчёты, управление сотрудниками. Ограничения проверяются на сервере.
- **Воронка продаж** — сделки по этапам с закреплением менеджера.
- **Заказы** — оформление с позициями из каталога и менеджером.
- **Клиенты** — с закреплением за менеджером.
- **Каталог** — 6448 товаров, правка цен/наименований, загрузка фото в карточку.
- **Дашборд** — сводные отчёты, воронка, заказы по статусам, разрез по менеджерам.

## API (кратко)
`POST /api/auth/login|logout`, `GET /api/auth/me`,
`/api/employees`, `/api/clients`, `/api/deals`, `/api/orders`,
`/api/products` (+ `POST /api/products/:id/image`), `/api/reports/dashboard`.
