# КРЕПОЛИТ — интернет-магазин крепежа и метизов

Многостраничный интернет-магазин оптовой и розничной продажи крепежа и метизов
«КРЕПОЛИТ — крепёж и метизы оптом». Аналог витрины строительного метизного маркета
(в нише fikser.ru), собственная вёрстка и контент.

## Структура

Статический сайт из отдельных HTML-страниц с общими стилями и скриптом —
разворачивается на любом веб-сервере (nginx, Apache, любой статический хостинг), сборка не нужна.

- `index.html` — главная (hero, категории, популярные товары, о компании, новости).
- `catalog.html` — каталог: сайдбар категорий, сортировка, фильтр `?cat=` и поиск `?q=`.
- `product.html` — карточка товара `?id=` (галерея, цена, количество, характеристики, похожие).
- `cart.html` — корзина и оформление заказа.
- `about.html` — о компании.
- `delivery.html` — доставка и оплата.
- `news.html` — новости.
- `contacts.html` — контакты и реквизиты.
- `assets/style.css` — все стили сайта.
- `assets/app.js` — данные каталога (16 категорий, 44 товара), корзина на
  `localStorage`, общая шапка/подвал/меню/модалки, поиск. Иконки — инлайновый SVG.
- `favicon.svg`, `robots.txt`, `sitemap.xml`.

## Возможности

- Каталог из 16 разделов и 44 товаров с артикулами, ценами, единицами и тегами.
- Поиск по названию и артикулу, сортировка, фильтр по категориям.
- Карточки товара с характеристиками и похожими позициями.
- Корзина (`localStorage`): количество, расчёт доставки, оформление заказа.
- Формы-заявки: обратный звонок, прайс-лист, сертификаты, оформление.
- Полностью адаптивный, без внешних зависимостей.

## Просмотр

Локально: откройте `index.html` в браузере (переходы между страницами работают
по относительным ссылкам). Либо отдайте папку любым статическим веб-сервером.
