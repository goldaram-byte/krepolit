Как устроена админка

Это статический сайт — без сервера и базы данных. Весь каталог лежит в файле assets/products.js (объект window.KATALOG: группы, подгруппы, товары с ценами).

Обзор — сводка по каталогу.

Каталог — просмотр, поиск и правка наименований/цен. Правки живут в браузере; чтобы они попали на сайт — «Экспорт products.js» → заменить файл в репозитории → запушить.

Заявки — заявки, оставленные на этом устройстве. Для полноценного приёма заявок (с воронкой, статусами, доступом с телефона) нужен backend — это отдельный шаг.
